Quick start → Read the API docs
Heads up: this Cloudflare page is a static landing site only. The payment gateway itself is a stateful Node.js ≥ 22.5 server (Express + embedded SQLite or Postgres) and cannot run on Cloudflare Workers/Pages. So this-url.workers.dev/admin will show a 404 — the merchant dashboard and login page will NOT appear here. To run the gateway, deploy it on Render, Docker, a VPS, or any Node host — see docs/DEPLOYMENT.md (বাংলা guide included) and docs/MIGRATE-FREE-HOST.md for $0 always-on alternatives. Once it's deployed on a Node host (optionally behind Cloudflare Tunnel), your merchant dashboard lives at https://pay.yourdomain.com/admin.

Payment rails

No gateway can move money with truly zero cost — the networks charge something. What you get here: zero monthly/setup fees, and rails that are genuinely free to run.

📱 Bangla QR Free

Customer scans your own bank-issued Bangla QR with any bank/MFS app → pays → enters TrxID → you approve. No SSLCommerz enrollment, no API fees.

💸 bKash / Nagad / Rocket / Upay / Bank Free

Manual verification: customer sends money to your own wallet/account, you approve in the admin dashboard, a signed webhook fires.

Payment approve হওয়ার flow

Manual/Bangla QR-এর ক্ষেত্রে নিজে নিজে paid mark হয় না — এটা যেন fraud হয় (customer মিথ্যা TrxID দিতে পারে); merchant verify করে approve দেয়:

  1. Customer checkout page-এ (/pay/:id) আপনার bKash/Nagad/Rocket নম্বরে বা Bangla QR-এ টাকা পাঠায় → TrxID + sender number দেয়
  2. Invoice pending থাকে — কোনো টাকা auto-credit হয় না
  3. Merchant /admin → Invoices-এ ঢুকে TrxID মিলিয়ে দেখে (নিজের bKash/Nagad app-এ) → Approve → invoice paid + webhook fire (payment.paid) → WooCommerce order auto-complete
  4. না মিললে → Reject → invoice failed

Note: Upay-এর আলাদা field /admin → Settings-এ নেই — Upay নিতে চাইলে Bank account details (free text) field-এ আপনার Upay নম্বর লিখে দিন, আর Customer instructions-এ "Upay-এ send money" mention করুন।

Up and running in 5 steps

Requirements: Node.js ≥ 22.5 (built-in node:sqlite). Node 24/26 recommended.

  1. git clone https://github.com/iamtanzir/FREE-Payment-Gateways.git && cd FREE-Payment-Gateways
  2. npm install
  3. npm start → open http://localhost:3000 — the admin password is printed once in the console
  4. /admin → API Keys → Create → copy your key
  5. Point your site at the REST API or drop the WordPress plugin in — full guide in MERCHANT-SETUP.md

Where can I deploy it?

Anywhere Node.js runs. Cloudflare Workers is the one place it can't — use Cloudflare as a proxy/tunnel in front of your host instead (see DEPLOYMENT.md §4F).
